# Kari-San — что нужно для полноценного запуска

Проверено 20 октября 2026 года. Платную CRM не подключаем: управление заказами и клиентами планируется внутри существующей админки.

## Что уже есть

- Сайт на украинском языке, адаптивный каталог из 84 товаров, карточки, корзина.
- База товаров, цены, варианты, остатки, архивирование и загрузка фотографий.
- Вход в админку по общей почте и паролю, закрытые серверные операции.
- Посещения, просмотры, корзина, начало оформления, источники, устройства, периоды и CSV. Посещения считаются по анонимным сеансам, а не по паспортно уникальным людям.
- Ручной журнал фактических продаж и возвратов. Это не автоматические заказы сайта и не выполнение банковского возврата.
- В этом обновлении: приблизительные страны посетителей, favicon, robots.txt и sitemap.xml с активными товарами. Исторические события без страны останутся «Неизвестно».

## Что нужно получить от владельца

| Что | Что предоставить | Для чего |
| --- | --- | --- |
| Хостинг и домен | Название провайдера, тариф, домен, доступные технологии; затем безопасно предоставить нужный доступ | Проверить совместимость и выбрать размещение без второго ненужного хостинга |
| Продавец | Подтверждённое название продавца/ФОП/компании, реквизиты, контакты, фактический адрес и график | Наполнить сведения магазина и подключить эквайринг |
| Условия работы | Куда доставляем, сроки отправки, условия доставки/возврата, кто оплачивает пересылку | Покупатель должен видеть реальные условия, а не выдуманный текст |
| Нова пошта | Кабинет отправителя, API-доступ, данные отправителя и место отправления | Выбор отделений, накладные и статусы по возможностям кабинета |
| Укрпошта | Кабинет, доступ к API и согласованные данные/условия отправителя | Отделения и оформление отправлений по доступному API |
| Онлайн-оплата | Выбранный провайдер, торговый кабинет, пройденная проверка и тестовые/боевые API-данные | Принимать оплату на счёт продавца |
| Товары | Проверка цен, размеров, остатков, фото и прав на материалы | Каталог был импортирован как снимок, не как непрерывная синхронизация |
| Уведомления | Рабочая почта магазина; есть ли отправка почты у текущего хостинга | Сообщения покупателю и владельцу без обязательной SMS-подписки |

Пароли, секреты эквайринга и ключи API не публикуются в GitHub или переписке. Перед подключением согласуем безопасный способ доступа. Регистрацию торгового кабинета, договоры, реквизиты и необходимые подтверждения выполняет владелец. С бухгалтером нужно уточнить фискализацию и чеки для выбранной схемы продаж.

## Что доделываем в коде

1. **Настоящий заказ.** Сервер принимает состав корзины и контакты, сам сверяет цены и остатки, резервирует товар, создаёт номер заказа и подтверждение. Повторное нажатие не создаёт дубликат. Определяем срок и снятие неоплаченного резерва. Контакты покупателя доступны только администратору.
2. **Мини-CRM без отдельной подписки.** Разделы «Заказы» и «Клиенты», история, поиск, статусы обработки, комментарии, доставка, оплаты и возвраты. Не передаём данные внешней CRM без необходимости. Общий логин не позволяет различать сотрудников; при необходимости добавим отдельные аккаунты.
3. **Доставка.** Поиск города/отделения, проверка доступности, накладные, номера и статусы; корректное поведение при недоступности перевозчика. До получения данных кабинетов нельзя подтвердить живую интеграцию.
4. **Оплата.** Сервер создаёт платёж и обрабатывает проверенное уведомление провайдера. Сверяются номер, сумма и валюта; повторные уведомления не удваивают поступление. Возврат из браузера сам по себе не подтверждает оплату. Платёжные данные карты сайт не хранит.
5. **Возвраты.** Отдельная запись каждой операции: дата, сумма, статус, идентификатор провайдера, возвращённые позиции. Несколько частичных возвратов считаются по своим датам. Возврат денег и возвращение товара на склад — разные действия.
6. **Автоматическая статистика.** Покупки и поступления из подтверждённых операций, отдельно неоплаченные/отменённые заказы, возвраты и источники. Сопоставление с ручными чеками защищает от двойного учёта. Страна посещения приблизительна; страна доставки берётся из заказа. Имя покупателя узнаём из заказа, а не из анонимного посещения.
7. **Политики и оформление.** Подтверждённые владельцем условия доставки, возврата, обработки данных, сведения продавца и понятное подтверждение заказа. Основной язык — украинский, валюта — гривна. Не обещаем международную доставку, пока она не согласована.
8. **Хостинг и эксплуатация.** Домен и HTTPS, секреты, доступ к базе/файлам, почта, резервные копии и пробное восстановление. Текущий сервер работает на Cloudflare Workers с D1/R2: для другого хостинга может потребоваться перенос серверной части. Простое копирование HTML не переносит базу и заказы.

## Проверка перед открытием продаж

- [ ] Цена и остаток в карточке, корзине и заказе согласованы; сервер отклоняет устаревшие данные.
- [ ] Телефон, получатель, город и отделение проходят проверку; ошибка перевозчика не оставляет покупателя без объяснения.
- [ ] Оформление работает на телефоне и компьютере, повторная отправка не создаёт два заказа.
- [ ] Успешная оплата, отказ, закрытая вкладка, задержанное и повторное уведомление дают правильные статусы.
- [ ] Отправка, отмена, полное и несколько частичных возвратов корректно меняют финансы и остатки.
- [ ] Заказ появляется в админке, уведомление доставляется, покупатель видит номер и подтверждение.
- [ ] Покупатель не может видеть чужие контакты, заказы или статистику; закрытые API проверяют вход на сервере.
- [ ] Статистика различает посетителя, оформление, заказ и подтверждённую покупку; тестовые операции отделены от рабочих.
- [ ] Проверены домен, HTTPS, мобильная версия, индексация активных товаров и резервное восстановление.
- [ ] После тестового режима владелец проводит согласованный реальный платёж и возврат; проверяются кабинет провайдера и выплата.

## По расходам

Отдельная подписка CRM для встроенного варианта не нужна. Новый платный хостинг не оформляем до проверки уже имеющегося. Нельзя обещать нулевую стоимость всего магазина: могут действовать стоимость текущего хостинга/домена, комиссия эквайринга, тарифы перевозчиков и выбранных уведомлений. Ничего платного не подключается автоматически.
